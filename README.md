# Ayo Sekolah!
1. Buat repo baru di GitHub, upload semua isi folder ini (termasuk folder .github).
2. Buka tab Actions, jalankan "Build APK" (juga jalan otomatis setiap push).
3. Setelah selesai, download artifact "ayosekolah-apk", ekstrak, lalu install app-debug.apk di HP.
Coba cepat tanpa build: buka www/index.html di browser HP.

Taruh suara karakter di folder ini (mp3, ogg, atau wav). Pakai nama file persis seperti ini:
  start.mp3  - saat mulai lari
  jump.mp3   - saat loncat
  slide.mp3  - saat meluncur
  hit.mp3    - saat terkena rintangan ("aduh!")
  die.mp3    - saat kesiangan / nyawa habis
  boost.mp3  - saat ambil pisang ("wuuus!")
  win.mp3    - saat sampai di sekolah
Kalau file tidak ada, game memakai efek suara bawaan.
